## 8. Pipeline complet

Construeix progressivament un pipeline que:

1. obtingui tots els processos;

>get-process
    
2. deixi només els processos amb `CPU > 5`;

>Get-Process | where-object {$_.cpu -gt 5}
    
3. deixi, a més, només els processos amb `Id > 1000`;

>Get-Process | where-object {$_.cpu -gt 5 -and $_.id -gt 1000}
    
4. els ordeni de major a menor CPU;

>Get-Process | where-object {$_.cpu -gt 5 -and $_.id -gt 1000} | sort-object cpu -descending
    
5. mostri només els cinc primers;

>Get-Process | where-object {$_.cpu -gt 5 -and $_.id -gt 1000} | sort-object cpu -descending | select-object -first 5
    
6. mostri només les propietats:

```
Name
Id
CPU
```

>Get-Process | where-object {$_.cpu -gt 5 -and $_.id -gt 1000} | sort-object cpu -descending | select-object name,id,cpu -first 5

# 10. Conclusions

Explica amb les teves paraules:

1. Per a què serveix `Select-Object`?

>serveis per triar les propietats que vols veure o les posicións. 
    
2. Quina diferència hi ha entre seleccionar **objectes** i seleccionar **propietats**?

>els objectes son per exemple els processos, cada process es un objecte, les propietats son tots els elements que te aquell objecte. 
    
3. Quina diferència hi ha entre `Get-Member` i `Select-Object *`?

>get-member enseña la estrucutra de un objecte, totes les propietats que te, el tipus de propietat, sense mostra valors de les propietats com a tal. 

>select-object mostra tots els valors de totes les propietats.
      
4. Per a què serveix `Where-Object`?

>Ens permet comparar propietats de objectes, com hara si la cpu es mes de un porcentatge. 
    
5. Què representa `$_`? I `$_.CPU`?

>$_ respresenta totes les propietats que envia el pipie, $_.CPU representa nomes el valor de la propietat de cpu. 
    
6. Què passa amb un objecte quan la condició de `Where-Object` retorna `True`? I quan retorna `False`?

>quan retorna True vol dir que la condició es compleix, quan retorna False vol dir que la condicio no es compleix. 
     
7. Explica què entra, què surt i què fa cadascuna de les etapes:
```
Get-Process |
    Where-Object {
        $_.CPU -gt 10 -and $_.Id -gt 1000
    } |
    Sort-Object CPU -Descending |
    Select-Object -First 5 Name, Id, CPU
```

>Primer entren tots els processos, d'aquests es fa un where object per aconseguir els que fan servir mes d'un 10 de cpu i la seva id es superior a 1000, llabors s'ordenen de manera que els processos amb més cpu apareixin primer, finalment sagafen els primer 5 i es mostra nomes el nom la id i la cpu

11. Es podria millorar l'ordre anterior fent alguna operació en un altre moment del pipeline? Justifica la resposta.

>No, ja esta correcte, estaria malament si primer es fes el sort-object, perque llavors hauria de processar molts de objectes.
