# ASIX Sistemes

Sóc **Bru Colomer**, estudiant de 2n d'ASIX. En aquest repositori documento com dissenyo i administro els sistemes de **MusicCloud**, l'empresa fictícia que fem servir com a cas pràctic al mòdul de ASIX-ASO.

## MusicCloud

MusicCloud és una empresa de producció musical que necessita reorganitzar la seva infraestructura informàtica: usuaris, grups, permisos i servei de directori.

## Contingut

- **01.Disseny**: anàlisi de l'empresa i disseny del servei de directori (OU, grups, LDAP i DIT).
- **02.Powershell**: exercicis de PowerShell per automatitzar l'administració dels sistemes.
